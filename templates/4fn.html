Cuarta Forma Normal (4FN)

No mezcles dos hechos independientes y multivaluados en una misma tabla.

1 ¿Qué dice la 4FN?

Una tabla está en Cuarta Forma Normal cuando está en FNBC y no tiene dependencias multivaluadas no triviales, salvo que el determinante sea una superclave.

¿Qué es una dependencia multivaluada?

Escribimos A →→ B cuando a cada valor de A le corresponde un conjunto de valores de B, y ese conjunto es independiente de las demás columnas. Un empleado tiene varias habilidades y varios idiomas; las habilidades no dependen de los idiomas.

Una tabla cumple la 4FN si:

  • ✔ Ya cumple la FNBC.
  • ✔ No guarda dos o más hechos multivaluados independientes sobre la misma entidad.

2 Ejemplo que NO cumple la 4FN

Se registran las habilidades y los idiomas de cada empleado en la misma tabla. Toda la tabla es la clave, así que no hay dependencias funcionales y ya está en FNBC. Pero empleado →→ habilidad y empleado →→ idioma son independientes.

empleado_habilidad_idioma

empleado (PK) habilidad (PK) idioma (PK)
Ana SQL Español
Ana SQL Inglés
Ana Python Español
Ana Python Inglés
Luis Java Español
Luis Java Quechua

¿Por qué es un problema?

  • Combinaciones forzadas: 2 habilidades × 2 idiomas obligan a guardar 4 filas para Ana.
  • Inserción: si Ana aprende Docker, debes agregar una fila por cada idioma que habla.
  • Inconsistencia: si olvidas una de esas filas, parecerá que Ana usa Docker solo en español.

3 Cómo llevarla a 4FN, paso a paso

  1. Paso 1 · Identifica los atributos multivaluados

    Aquí: habilidad e idioma para cada empleado.

  2. Paso 2 · Verifica que sean independientes

    Pregúntate: ¿el idioma cambia según la habilidad? Si no, son independientes y deben separarse. Si sí (por ejemplo "da cursos de SQL en inglés"), la relación es un solo hecho y se queda unida.

  3. Paso 3 · Crea una tabla por cada hecho

    Una para empleado - habilidad y otra para empleado - idioma.

  4. Paso 4 · Define las claves

    En cada tabla, la PK es la combinación de ambas columnas.

4 Resultado: tablas en 4FN

empleado_habilidad

empleado (PK) habilidad (PK)
Ana SQL
Ana Python
Luis Java

empleado_idioma

empleado (PK) idioma (PK)
Ana Español
Ana Inglés
Luis Español
Luis Quechua

Agregar una habilidad nueva ahora es insertar una fila, sin tocar los idiomas.

5 Errores comunes

Separar hechos que sí están relacionados

Si el idioma depende de la habilidad, no son independientes y no hay dependencia multivaluada que eliminar.

Creer que FNBC ya lo resuelve

La FNBC solo considera dependencias funcionales; esta tabla las cumple todas y aun así tiene redundancia.

Buscarla solo en tablas con muchas columnas

El problema aparece con tres columnas, como aquí, siempre que dos de ellas sean independientes entre sí.

Resumen rápido

4FN = FNBC + sin dependencias multivaluadas independientes. Un hecho multivaluado por tabla.
